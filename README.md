# Alura_store

Este proyecto tiene como objetivo realizar un análisis de ventas y rendimiento de cuatro tiendas para ayudar al señor Juan a decidir cuál tienda debería vender para invertir en un nuevo negocio. A través de este desafío, se evaluarán diversos aspectos clave que permitirán tomar decisiones estratégicas basadas en datos.

Objetivos del Análisis
Se evaluarán los siguientes cinco aspectos:

Facturación Total: Determinar cuál tienda tiene la mayor facturación.
Categorías Populares: Identificar las categorías de productos más vendidas en cada tienda.
Promedio de Evaluación: Calcular el promedio de evaluación de los clientes para cada tienda.
Productos Más y Menos Vendidos: Analizar cuáles son los productos que más y menos se venden en cada tienda.
Costo Promedio de Envío: Evaluar el costo promedio de envío desde cada tienda hasta los clientes.
Herramientas Utilizadas
Para facilitar el análisis, se ha creado un tablero en Trello que incluye:

Sección de Herramientas: Instrucciones sobre cómo comenzar el proyecto.
Control de Versiones: Uso de GitHub para la gestión del código.
Backlog: Elementos necesarios para iniciar el proyecto, incluyendo análisis de datos y visualización.
Desarrollo: Secciones para simular un entorno de trabajo como analista de datos.
